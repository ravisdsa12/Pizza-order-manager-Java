# 🍕 Sistema de Gerenciamento de Pizzaria

Um sistema via terminal (CLI) desenvolvido em Java para automatizar a gestão de cardápios e pedidos de uma pizzaria. 

Projeto construído para praticar e consolidar conceitos fundamentais da programação e lógica de software.

---

### ✨ Funcionalidades

- 📋 **Gestão de Cardápio:** Cadastrar novas pizzas com nome, ingredientes e preço.
- 🛍️ **Atendimento e Pedidos:** Registrar novos pedidos.
- 💵 **Cálculo Automático:** Soma do valor total da comanda do cliente.
- 📜 **Exibição de Relatório:** Listagem clara dos pedidos em aberto.

---

### 🛠️ Conceitos Aplicados no Código

Este projeto foi uma oportunidade prática de aplicar os seguintes tópicos de Ciência da Computação:

- **Estruturas de Dados:** Uso de `[structs / listas / dicionários]` para criar a entidade "Pizza" e "Pedido".
- **Modularização:** Organização do código em funções com responsabilidades únicas.
- **Controle de Fluxo:** Laços de repetição (`while`) e menus interativos com validação de dados.
